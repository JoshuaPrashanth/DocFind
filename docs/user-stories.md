# User Stories

1. As a user, I want to upload multiple PDFs so that I can search them together.

2. As a user, I want to search a keyword so that I can quickly find relevant pages.

3. As a user, I want to know the PDF name and page number so that I can locate the information.

4. As a user, I want to see the preview of the pdf with exact page open if the PDF exits with the search word match.
